הוראות התקנה והרצה למערכת LuxStay OS - שלב ה׳
=============================================

כדי להפעיל את האפליקציה הגרפית מול מסד הנתונים PostgreSQL, יש לפעול לפי השלבים הבאים:

1. ודאו שתוכנת Docker Desktop פתוחה במחשבכם.
2. ודאו שהקונטיינר של מסד הנתונים (my_postgres_db) פועל ורץ.
3. פתחו את מסוף הפקודות (Terminal / CMD) בתיקיית APP1 והתקינו את הספרייה הדרושה לחיבור לפייתון:
   
   pip install psycopg2-binary

4. הריצו את האפליקציה באמצעות הפקודה:
   
   python app.py

5. המערכת תעלה ותתחבר אוטומטית למסד הנתונים המקומי.
   פרטי החיבור המוגדרים בקוד הם:
   - Host: localhost
   - Port: 5432
   - Database: mydatabase
   - User: or
   - Password: 1234
